# Daisuke Kuriyama

- Working on multi-agent pathfinding and swarm robotics with a 100-robot physical testbed and simulations of up to 10,000 robots.
- Maintaining [isutools](https://github.com/ekusiadadus/isutools), [draw-mcp](https://github.com/ekusiadadus/draw-mcp), and [rt-lacam](https://github.com/ekusiadadus/rt-lacam).
- Contributing to open source projects including [Rust](https://github.com/rust-lang/rust), [Ghostty](https://github.com/ghostty-org/ghostty), and [Biome](https://github.com/biomejs/biome).

## Featured projects

### [isutools](https://github.com/ekusiadadus/isutools)

A one-line Go profiler for ISUCON and performance tuning. It brings SQL, HTTP, reverse-proxy logs, pprof, host metrics, and benchmark diffs into one dashboard.

### [draw-mcp](https://github.com/ekusiadadus/draw-mcp)

A Claude Code skill and CLI validator for production-quality draw.io XML, with 31 validation rules, presets, and CI-ready checks.

### [rt-lacam](https://github.com/ekusiadadus/rt-lacam)

An implementation of Real-Time LaCAM for incremental multi-agent pathfinding, with a Zig core and Python bindings.
